# EduHub – MERN E-Learning Platform

EduHub is a full-stack e-learning platform built using the MERN stack (MongoDB, Express.js, React.js, Node.js). The platform provides course management, lecture access, authentication, and admin functionalities.

Developed as part of a collaborative team project.

## Features
- User Authentication
- Course & Lecture Management
- Admin Dashboard
- Protected Routes
- REST API Integration
